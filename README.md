# SweatSystem

SweatSystem is a mod for The Long Dark that simulates player perspiration based on perceived temperature.

The hotter the player feels, the more they sweat.  
The more they sweat, the wetter their clothes become.

... and that's pretty much about it.

## Development Status

SweatSystem is currently in an early stage and is not feature-complete.

The current implementation focuses on core temperature-to-wetness logic.  
The upcoming updates aim to introduce a more complex and responsive system, including more advanced environmental interaction, several features related to physical effort and probably mental condition (stress).

The mod is fully functional in its current state, but it represents only the foundation of the intended system.

## Installation

1. Install MelonLoader.
2. Place `SweatSystem.dll` inside your Mods folder.
3. Launch the game.

No dependencies are required.
